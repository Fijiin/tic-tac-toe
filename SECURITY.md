# Security Policy\n\n## Supported Versions\n\n| Version | Supported |\n|---|---|\n| Latest (`master`) | ✅ |\n\n## Reporting a Vulnerability\n\nPlease **do not** open a public GitHub issue for security vulnerabilities.\n\nReport privately by emailing: **filipklimes12@seznam.cz**\n\nInclude:\n- Description of the vulnerability\n- Steps to reproduce\n- Potential impact\n- Suggested fix (optional)\n\nExpect a response within 48 hours. Vulnerabilities will be addressed before any public disclosure.\n\n## Scope\n\nThis project is a client-side only web app (HTML/CSS/JS) with no backend, no user accounts, and no data storage. The main security surface is:\n\n- **XSS** — all user input (player names) is written via `textContent`, never `innerHTML`, so injected markup is never executed.\n- **Third-party dependencies** — there are none. No npm packages, no CDN scripts.\n- **GitHub Actions** — CI workflows use pinned action versions and minimal permissions.\n
